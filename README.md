# 🚀 Estudos de Programação

Bem-vindo ao meu repositório de **estudos e evolução em programação**.

Este repositório reúne exercícios, projetos, experimentos e aplicações desenvolvidas durante minha jornada como desenvolvedor. A ideia é registrar minha evolução prática, testar novas tecnologias e consolidar os conhecimentos adquiridos ao longo dos estudos.

---

## 🧑‍💻 Sobre mim

Sou estudante de **Tecnologia da Informação** e desenvolvedor em formação, com foco principalmente no desenvolvimento **Full Stack**, especialmente no ecossistema **Java + Spring Boot**.

Tenho estudado tanto o desenvolvimento de interfaces quanto o desenvolvimento de APIs e aplicações backend.

Meu objetivo é transformar conhecimento teórico em **projetos reais, código limpo e soluções funcionais**.
